# Aeon Sensor Panel

A retro-futurist hardware dashboard for your second screen. Every temperature, load, clock and watt in glowing amber, with escalating overheat alarms, suspicious-process flags and a week of history one click away.

## Download

Get the latest installer from **[Releases](https://github.com/AeonSystems/aeon-releases/releases/latest)**: `AeonSensorPanel-Setup-x.y.z.exe`. Once it's installed, the panel tells you when a new version is out.

The tester quick-start guide is attached to each release.

## Requirements

- Windows 10 or 11, 64-bit
- A second monitor (best on a 1920x720 bar screen or any 16:9 monitor)
- LibreHardwareMonitor (free; the installer finds it or sets it up for you)

## Privacy

We don't want your data. No accounts, no analytics, no telemetry, no ads, no tracking. **Nothing is sent unless YOU submit a report.** The full notice is PRIVACY.txt in the install folder.

## Support
